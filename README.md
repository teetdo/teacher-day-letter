# 💌 Chúc Mừng Ngày Nhà Giáo Việt Nam 20/11

Một ứng dụng web tương tác để gửi lời tri ân đến thầy cô nhân dịp Ngày Nhà Giáo Việt Nam 20/11.

## 🚀 Demo Live

**[Mở ứng dụng trực tiếp](https://htmlpreview.github.io/?https://raw.githubusercontent.com/teetdo/teacher-day-letter/refs/heads/main/10.html)**

## ✨ Tính năng

- 📬 Phong bì tương tác với hiệu ứng mở/đóng mượt mà
- 🎉 Hiệu ứng pháo hoa & trái tim khi mở thư
- 💌 Nội dung thư với hoạt ảnh chữ
- 📱 Responsive design - tương thích mọi thiết bị
- 🎨 Giao diện đẹp với gradient và animation

## 🚀 Cách sử dụng

### Cách 1: Xem trực tiếp online
1. Truy cập: https://teetdo.github.io/teacher-day-letter
2. Nhấn vào phong bì để xem hiệu ứng

### Cách 2: Chạy locally
1. Clone repository:
```bash
git clone https://github.com/teetdo/teacher-day-letter.git
cd teacher-day-letter
```

2. Mở file `10.html` trong trình duyệt

## 📁 Cấu trúc dự án

```
.
├── 10.html          # File HTML chính
├── 10.css           # Styling & animations
├── script.js        # JavaScript logic
├── .gitignore       # Git ignore file
└── README.md        # File này
```

## 🛠️ Công nghệ sử dụng

- HTML5
- CSS3 (Animations, Gradients, Flexbox)
- Vanilla JavaScript (Canvas API)
- Google Fonts

## 📝 Nội dung thư

Thư gửi đến thầy cô kỷ niệm 43 năm Ngày Nhà Giáo Việt Nam với:
- Lời tri ân chân thành
- Thơ ca tôn vinh nghề dạy học
- Những lời chúc tốt đẹp

## 🎨 Tùy chỉnh

Bạn có thể sửa đổi:
- **Nội dung thư**: Chỉnh sửa trong `10.html`
- **Màu sắc**: Thay đổi CSS variables trong `10.css`
- **Hiệu ứng**: Điều chỉnh trong `script.js`
